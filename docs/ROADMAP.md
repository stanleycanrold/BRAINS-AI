# Roadmap

## Phase 0 — Foundations (this week, after flow is confirmed)
- Next.js + TS + Tailwind scaffold (shared design tokens)
- Auth + DB connection
- `ideas` + `hypotheses` schema and capture screen

## Phase 1 — Validation MVP (the core wedge)
- Stage 0 capture + hypothesis builder
- Stage 1: interview prompt generator, evidence log, signal scoring, kill/pivot/build
- Single-founder, self-serve, one idea at a time

## Phase 2 — Offer & launch path
- Stage 2 offer/positioning
- Stage 3 one-job MVP scoping + first-customer motion templates

## Phase 3 — Traction & multi-idea
- Stage 4 metrics dashboard
- Multiple ideas per founder, comparison view

## Phase 4 — Monetization & polish
- Paywall at the first paying moment (TBD)
- Onboarding, sharing/export, team seats

We validate our own build the same way we tell founders to: ship the one-job wedge (validation MVP)
first, get founders using it, then expand.
